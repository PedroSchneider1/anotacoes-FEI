# Anotações
Repositório criado para armazenar as anotações feitas durante meu curso na FEI.
Todos os arquivos *markdown* (.md) foram criados pelo aplicativo **Obsidian**, portanto a formatação no github não será correspondente (ex: fórmulas matemáticas foram criadas usando LaTeX, integração plena somente pelo aplicativo).

> Para visualizar os arquivos de maneira plena, é necessário baixar o [Obsidian](https://obsidian.md/) e abrir as notas por lá.
